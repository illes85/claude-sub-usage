# sub-usage

Claude Code plugin that shows your Claude subscription usage:

- status line: `5h 42.5% · Weekly 91%`
- a bar above the prompt with progress, percent and time to reset
- toast warnings at 80 / 90 / 100%
- `/usage-bar` toggles the bar

Only subscription (non-API-key) accounts report limits.

## Install

```
/plugin install sub-usage --marketplace illes85/claude-sub-usage
```
